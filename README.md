# IPoverObexVxp
Client app to connect by bluetooth to server app for MRE platform mobile phone (including Nokia S30+). Like chat. On server sudo ./IPoverObexPC, in additional server console nc 127.0.0.1 400. Swich to local mode on phone (console commands) with key * + [Swch].
For using with Nokia mobile phone, app must be signed with IMSI (your SIM card) code. https://vxpatch.luxferre.top
Application files - "[IPoverObexTest.vxp](https://github.com/RDZDX/IPoverObexVxp/blob/main/IPoverObexTest.vxp?raw=true)" "[IPoverObexPC](https://github.com/RDZDX/IPoverObexVxp/blob/main/IPoverObexPC?raw=true)" [32 bit binary for Raspberry Pi Zero W Debian Bookworm (12)].
