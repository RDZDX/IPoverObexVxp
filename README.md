# IPoverObexVxp Bluetooth P2P chat

A symmetric Bluetooth peer-to-peer chat application for MRE phones (including Nokia S30+). Both phones run the same binary.

## Usage

1. Pair both phones over Bluetooth.
2. Launch IPoverObexVxp on both phones.
3. On startup the app uses that phone's Bluetooth device name from system settings as the chat sender name.
4. Choose:
   - **Listen** to wait for incoming peer connection, or
   - **Connect** to pick a paired device and connect.
5. Type message text and press OK to send.

## Nokia Phone Signing

For use on Nokia mobile phones, the application must be signed using the IMSI code of your SIM card.

More information: https://vxpatch.luxferre.top
