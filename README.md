# IPoverObexVxp
Client app to connect by bluetooth to server app for MRE platform mobile phone (including Nokia S30+). On active connection phone app switch to chat mode. On server start bluetooth service and sudo ./IPoverObexPC, in additional server console nc 127.0.0.1 400. Can swich to local mode on phone (for console commands) with key * + [Swch]. Phone must be initialy paired and trusted by BT with server BT.
For using with Nokia mobile phone, app must be signed with IMSI (your SIM card) code. https://vxpatch.luxferre.top
Application files - "[IPoverObexTest.vxp](https://github.com/RDZDX/IPoverObexVxp/blob/main/IPoverObexTest.vxp?raw=true)" "[IPoverObexPC](https://github.com/RDZDX/IPoverObexVxp/blob/main/IPoverObexPC?raw=true)" [32 bit binary for Raspberry Pi Zero W Debian Bookworm (12)].
